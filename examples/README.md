# Public example dataset

The repository includes two small, source-attributed course records to make the application runnable without a large scrape. These are selected metadata fields, not complete course plans or a comprehensive NIT Trichy dataset.

- [AR507 — Architectural Design VIII, July 2026](https://cp.nitt.edu/upload/course_pdfs/AR507_July2026.pdf)
- [CA6D3 — Natural Language Processing, January 2026](https://cp.nitt.edu/upload/course_pdfs/CA6D3_Jan2026.pdf)

The CA6D3 instructor and coordinator were checked against page 1 of the official plan on 28 October 2026. Teaching assignments belong to the stated session. No downloaded PDFs, student records, phone numbers, or email addresses are included in this example.

Run `python3 scripts/use_demo_data.py` to copy these records into the ignored local `data/` directory. Existing application data is preserved.
